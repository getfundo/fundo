# Security policy

## Supported versions

Fundo is in early development. Only the latest release and the `main` branch receive security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub:
**Security tab → [Report a vulnerability](https://github.com/getfundo/fundo/security/advisories/new)**.

Include as much of the following as you can:

- A description of the issue and its impact
- Steps to reproduce, or a proof of concept
- The affected version or commit

We will acknowledge your report as soon as possible, keep you updated while we investigate, and credit you in the fix if you wish.

Please give us a reasonable amount of time to release a fix before disclosing the issue publicly.
